Subordinate strictly to root `AGENTS.md` and `.agents/rules/00-constitution.md`. ## 2. Asymmetric AI Usage: Adversarial Auditor Over Volume Generator

- **Default workflow mode:** Deploy AI offline as an **adversarial auditor** (hunting cross-chapter contradictions, silent compensatory trade-offs, weak rival hypotheses $\neg H$ in Process Tracing, symbol collisions, and unverified sources) rather than an unchecked prose expander.
- **Tier-Wide Anti-Compliance-DoS Diff Budget (`Ch. 95`, $10\text{ bits/s}$, `--strict-bloat`):** Unnecessary expansion across any custody tier (`tier1-invariant-core`, `tier2-reversible-periphery`, or `tooling-only`) taxes human review queues into $\rho_{\mathrm{cog}} \to 1^-$. Keep diffs surgical, prefer tightening over padding, and enforce all `--strict-bloat` bounds via `check_custody_provenance.py`:
  - **Prose (`book-src/*.md`, `.svg` text, `README.md`, `CONTRIBUTING.md`):** `<= 250` positive net / gross added lines, `<= 400` total churn lines, `<= 2000` positive net words, `<= 5000` gross word-diff added; per file `<= 80` net / `<= 100` gross lines, `<= 1000` net / `<= 1500` gross word-diff.
  - **Governance (`AGENTS.md`, `.agents/{rules,skills}/`, `.github/workflows/`, `.pre-commit-config.yaml`, `.gitmessage`, `book.toml`, `CITATION.cff`, `.cargo/`, `rust-toolchain*`):** `<= 450` added / `<= 650` churn lines (`<= 250`/file), `<= 4500` word-diff added (`<= 2000`/file), `<= 45000` added bytes (`<= 20000`/file).
  - **Code (`.agents/scripts/`, `.github/checks/`, `crates/`, `adapters/`, `consumers/`, `Cargo.{toml,lock}`, `mathjax.js`, `theme/`):** `<= 5200` added / `<= 5800` churn lines (`<= 3200`/file), `<= 25000` word-diff added (`<= 14000`/file), `<= 260000` added bytes (`<= 150000`/file).
  - **Reviews (all `reviews/` including pointers):** `<= 3000` added lines (`<= 450`/file), `<= 25000` word-diff added (`<= 4000`/file), `<= 220000` added bytes (`<= 35000`/file).
- **Human-Scale Structural Maps (Anti-Opaque-Correctness, `Ch. 56` & `Ch. 95`):** Every AI-generated or AI-verified proof, theorem, or code patch submitted for `Human-T1-Signoff` MUST attach a compact human-scale structural map (enforced in `_validate_blind_review_artifact`: `5..150`-word `## Audited Central Thesis`, structured `## Findings`, and concise `## Verification` within `<= 450` lines / `<= 35,000` bytes rather than raw machine dumps), keeping audit cost inside the `10 bits/s` deliberate-attention budget.

## 3. Strict Generator–Oracle Separation (Anti-Circularity)

- **Hard Separation Rule:** Never validate AI-generated or AI-patched prose, derivations, code, or citations inside the same context window or prompt that produced them.
- Every authorized **Patch Mode** change must clear three independent oracle layers before human acceptance:
  1. **Zero-LLM Deterministic Gauntlet:** `python3 .agents/scripts/check_crossrefs.py --full-report` (covering `structure.py`, `check_graphs.py`, `check_notation.py`, `check_crossrefs.py`, `check_symbolic_math.py`, `check_style_and_citations.py`, and `check_custody_provenance.py`).
  2. **Build & Core Parity:** `mdbook build`, `python3 .github/checks/surface.py book`, `python3 .github/checks/build_pdf.py book book/stochology.pdf` (when `book-src/` changes), plus `cargo test --workspace --offline` and `cargo test --offline --manifest-path crates/host-workspace/Cargo.toml` (when `crates/` or core-linked specifications change).
  3. **Blind Isolated Review:** Spawn fresh isolated specialist subagents (`/review-chapter` cells with zero drafting context, using distinct models where available) to audit the patched files for mathematical gaps, capture loopholes, and source fidelity.
- **Irreducible Human Authority (`T1`):** Automated gauntlets have zero power over unencoded specification omissions ($\Omega_{\mathrm{unspec}}$, `Ch. 56`). Only the human author owns `T1` framing, architectural boundary choices, `SUMMARY.md` retitlings, and final merge sign-off.
- **Syntactic-Gauntlet Threat-Model Boundary (`Chs. 56, 83, 95`):** Deterministic regular-expression screens in `_custody_identity.py` (verdict-vs-prose consistency checks on blind review reports) and the line-oriented CommonMark subset scanner in `check_style_and_citations.py` operate as **defense-in-depth Layer-0 syntactic filters**, never as a complete semantic oracle over unbounded natural-language paraphrases, adversarial typographic/LaTeX obfuscations, or deeply nested CommonMark corner cases. Extending regex inventories indefinitely against an open natural-language space cannot converge and induces Compliance DoS (`Ch. 95`) while degrading script auditability. Residual open-ended prose-contradiction paraphrases and exotic CommonMark container edge cases beyond verified regression baselines are bounded structurally by **independent non-author post-patch review commits, isolated multi-model blind audits, and distinct `Human-T1-Signoff`**, rather than unbounded regex expansion. Any future hardening of those screens must preserve existing regression coverage without weakening structural trailer, identity, actor-separation, or diff-bloat gates.

## 4. Anti-Atrophy Protocol & Sealed Human Vintages in Git (`Chs. 49, 75`)

- **Preserve Human *Melétē*:** Conceptual nuclei (Prologue `00`, chapter opening scenarios, `T1` framing passages, `## Bridge` argument handoffs, and core proofs) remain human-authored or human-led so unassisted diagnostic adroitness ($a_{\mathrm{skill}, t} \ge a^\star_{\mathrm{skill}}$) never decays under passive AI reliance.
- **Git Authorship Provenance Trailers:** Record provenance explicitly in commits using `.gitmessage` trailers (no angle-bracket placeholders or `TBD`/`pending` tokens allowed):
  - `Authorship-Vintage: human-original | human-led-ai-assisted | ai-audit-only | deterministic-script` *(with `ai-audit-only` permitted strictly on `tooling-only` commits under `reviews/`)*
